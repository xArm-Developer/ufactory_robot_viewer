## Robots & Accessories

Default scene: `xArm 6`, no rail, no end tool, all joints and rail at zero. `xArm 5/6/7` are the 1305 version.

| Robot | Linear Rail `AL0700` | F/T Sensor `AI1500` | End Effectors |
| --- | :---: | :---: | --- |
| `xArm 5/6/7` | ✓ | ✓ | `Gripper G2`, `BIO Gripper G2` |
| `850` | — | ✓ | `Gripper G2`, `BIO Gripper G2` |
| `Lite 6` | — | — | `Gripper Lite`, `Vacuum Gripper Lite` |

| End Effector | Opening |
| --- | --- |
| `Gripper G2` | `0–84 mm`, step `0.1 mm` |
| `BIO Gripper G2` | `71–150 mm`, step `0.1 mm` |
| `Gripper Lite` | Pneumatic, `0` closed / `100` open |
| `Vacuum Gripper Lite` | Static model |

- Switching accessories keeps the current pose; switching robots keeps compatible accessories and drops the rest. Invalid input reverts to the last valid value.
- The scene (model, pose, accessories) is stored locally in the browser, written with a `200 ms` throttle during continuous motion. On load, the saved scene is restored first; if invalid or colliding, it falls back to the link scene, then to `xArm 6` at zero with no accessories.

## TCP Offsets

Fixed offsets in the flange frame (mm):

| End Configuration | TCP Position `(x, y, z)` |
| --- | --- |
| None | `(0, 0, 0)` (flange) |
| `AI1500` | `(0, 0, 58.6)` |
| `Gripper G2` | `(0, 0, 173.5)` |
| `BIO Gripper G2` | `(135, 0, 55)` |
| `Gripper Lite` | `(0, 0, 83.6)` |
| `Vacuum Gripper Lite` | `(0, 0, 61.0)` |

- `AI1500` + gripper: the gripper offset is shifted by `+Z 58.6`.
- The TCP does not change with gripper opening or rail travel.

## Motion Control

Joint, Cartesian and rail controls share one speed `1%–100%` (default `50%`, saved locally), mapped linearly:

| Control | Short-press Step | Long-press (> `220 ms`) Speed |
| --- | --- | --- |
| Joint | `1°` | `1–45°/s` |
| Cartesian position / orientation | `1 mm` / `1°` | `2.5–250 mm/s` / `1–40°/s` |
| Linear rail (`0–700 mm`) | `1 mm` | `2.5–250 mm/s` |

- **Initial position**: moves all joints to `0°`, keeping rail and end configuration.
- **Level flange**: adjusts only the last three joints, choosing the in-limit solution with minimal squared joint change so that flange `+Z` is within `0.1°` of base `−Z`; if unreachable, the pose is kept and a notice is shown.
- Continuous motion stops on release, tab/scene switch, panel collapse or blur. `Roll±` is disabled for `xArm 5`.

## Collision Detection & Visualization

- Each step checks joint limits and geometric collisions (self-collision, robot vs. accessories including the `AL0700` drag chain; the ground is excluded). On collision, the pose reverts to the last valid one, colliding parts turn red and the colliding pair is shown.
- Non-converged IK keeps the pose; out-of-limit solutions show `C23 Joints Angle Exceed Limit ID [x], joint angle [1.23°].`.
- The ground ring is the theoretical maximum horizontal reach of the TCP on the base `z=0` plane (joint limits only, free orientation, no collision), from offline data.
- Telemetry shows the TCP pose in `link_base` (mm, °); RPY uses fixed axes `Rz(yaw) × Ry(pitch) × Rx(roll)`.

## Example 01: Packing Physics Simulation

- Scene: `xArm 6 + Gripper G2`, conveyor at `40 mm/s`, nine `30 mm`, `17 g` parts; stops once all are settled in the box. State is independent from the robot page.
- Engine: [MuJoCo 3.15.0 single-thread WASM](https://github.com/google-deepmind/mujoco/blob/3.15.0/wasm/README.md). Parts are free bodies carried by conveyor [surface velocity](https://mujoco.readthedocs.io/en/3.13.0/XMLreference.html#body-geom-surfacevel); grasping relies on actuators, contact friction and gravity, without weld constraints. Actuator and friction parameters are for demonstration.
- Missed grasps, drops, unsettled parts and unexpected collisions stop the run with a notice. No real robot is connected; not a safety validation.
- The MJCF is generated by [`scripts/build-packing-model.py`](../scripts/build-packing-model.py) from the URDF, [`src/packing-config.json`](../src/packing-config.json) and collision hulls.

## Deep Link Parameters

| Parameter | Values | Applies To |
| --- | --- | --- |
| `example` | `packing-01` | — |
| `model` | `xarm5`, `xarm6` (default), `xarm7`, `uf850`, `lite6` | — |

| `gripper` | `gripper-g2`, `bio-gripper-g2` / `lite6-gripper`, `lite6-vacuum-gripper` | Compatible robots |

- Example: `?model=xarm7&rail=al0700&railPos=280.5&sensor=ai1500&gripper=bio-gripper-g2&opening=110.0`.
- Invalid parameters fall back to defaults and the URL is updated. Legacy `?model=ai1500|gripper-g2|bio-gripper-g2` converts to an `xArm 6` assembly; `?model=lite6-gripper|lite6-vacuum-gripper` converts to a `Lite 6` assembly.

## Asset Caching & Offline Pipelines

- At build time, GLBs larger than `128 KiB` that shrink by ≥ `20%` get gzip copies (SHA-256 named, `.bin` suffix) with long-term caching via `_headers`; browsers without the decompression API use the original files.
- The runtime decoded model cache is capped at `64 MiB` and `ModelCache` is shared across pages.

| Script | Purpose |
| --- | --- |
| [`build-collision-hulls.py`](../scripts/build-collision-hulls.py) | Generate collision hulls `public/models/<id>/collision.json` |
| [`reach-input.mjs`](../scripts/reach-input.mjs) + [`generate-reach.py`](../scripts/generate-reach.py) | Compute reach radii for 27 assemblies into [`reach-data.json`](../src/reach-data.json) |
| `generate-mujoco-*-fixtures.py`, [`packing-physics.py`](../tests/packing-physics.py) | Generate FK and collision ground truth; packing physics check |

Regenerating hulls or collision fixtures requires read-only [UFACTORY Genesis](https://github.com/xArm-Developer/ufactory_genesis) `assets/urdf` (default `../ufactory_genesis/assets/urdf`, override with `UFACTORY_GENESIS_URDF_DIR`). Gripper FK fixtures use [`tests/reference-urdfs/`](../tests/reference-urdfs/).
